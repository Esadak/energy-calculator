# ⚡ EnergyKoll AI (Energy Calculator)

En webbapplikation som hjälper svenska hushåll att sänka sina energikostnader med hjälp av artificiell intelligens. Användaren får personliga rekommendationer och konkreta besparingsförslag baserat på sin bostadsprofil.

## 🚀 Funktioner
- AI-driven analys: Använder Google Gemini AI för att generera skräddarsydda energitips.
- Interaktiv kalkylator:Beräknar potentiell månatlig och årlig besparing.
- Modern UI/UX: Responsiv design byggd med Tailwind CSS.
- Admin Dashboard: (Dolt) För att spåra statistik, användardata och exportera CSV.

## 🛠️ Tech Stack
- Frontend:  Next.js 14 (App Router), React, TypeScript
- Styling: Tailwind CSS, shadcn/ui
- AI:  Google Gemini API
- Autentisering: NextAuth.js
- Deployment: Vercel
- URL: https://www.energykoll.se/
